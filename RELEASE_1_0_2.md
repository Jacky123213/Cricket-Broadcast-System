# Cricket Broadcast System 1.0.2

Desktop app 1.0.2 · Scoreboard graphics 0.3.2 · DRS engine 0.15.2.

## Included

- Combined local Windows desktop for replay, scoring, settings and troubleshooting.
- Responsive browser camera and umpire pages for Apple, Android and Raspberry Pi devices.
- Shared live camera output and transparent scoreboard/graphics for OBS.
- Manual graphics controls, editable recorded innings stats, drinks card, innings-break graphic and match summary.
- LAN HTTPS overlay/broadcast links using the same local certificate as cameras and the umpire console, for OBS on another PC.

## Overlay fixes

- The coloured bottom line now spans the entire scorebar.
- Colours and logos are saved against team names, not batting/bowling positions. They follow manual changes, starting a chase and Bluetooth team-name updates.
- Split team-name updates and a shortened-innings reset preserve first-innings history.
- Projected totals are one information-strip message: the current RPO and three higher whole-number rates, with each projected total alongside its rate. They no longer occupy consecutive rotation slots.
- Appearance labels identify the team being edited. Cache-busted desktop/overlay assets prevent the old controls loading after an upgrade.

## Install or upgrade

1. Extract the release to its own folder on Windows.
2. Install 64-bit Python 3.11 or newer with the Python launcher, then run `SETUP_WINDOWS.bat` once while online.
3. Start `START_STUDIO.bat`. The home page should show **Studio 1.0.2 · Overlay 0.3.2**.
4. For an existing installation, close Studio and its launcher before replacing source files. Keep your local `certs`, `data` and `storage` folders; do not copy these folders to GitHub or another installation.
5. Refresh existing OBS browser sources. On a separate OBS PC, use the preferred LAN HTTPS overlay address from Settings and trust only the public CA certificate generated by your own installation. See `OVERLAY_GUIDE.md`.

## Limits

- This is a Python-based Windows application, not a standalone compiled installer.
- Bluetooth reception requires a compatible Windows peripheral-mode adapter/driver.
- Actual mobile camera selection depends on device/browser support. ESP32/Arduino MJPEG sources remain broadcast-only, not synchronized replay angles.
- The second OBS PC and physical Apple/Android/Pi cameras require on-device testing on your network.
- The repository has no licence for now, as requested. Certificates, match data, recordings, logs and virtual environments are intentionally not distributed.
